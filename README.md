# ⚡ React Function Demos

A collection of simple examples demonstrating how different React features and functions work. This repository serves as a quick-reference guide and playground for learning fundamental React concepts.

---

## 🚀 Getting Started

Follow these steps to run the code snippets locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/ideesh/react-function-demos.git
cd react-function-demos
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
